# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 5.x     | ✅ |
| < 5.0   | ❌ |

## Reporting a Vulnerability

This is a research tool for authorized arXiv endorsement outreach. If you find a security vulnerability:

1. **Do not** open a public GitHub issue
2. Email the maintainer at aditya@example.com
3. Include a description, reproduction steps, and impact assessment

You should receive a response within 48 hours.

## Responsible Use

- Only use with your own email accounts
- Respect arXiv's endorsement system terms of service
- Do not use for spam or unsolicited bulk email
- Ensure compliance with CAN-SPAM Act and GDPR
